# Device artwork

Artwork is loaded only when a popup needs it. Add transparent PNG files here using these names:

- `SurfaceEarbuds_Case.png`
- `SurfaceEarbuds_Buds.png`
- `SurfaceHeadphones.png`
- `SurfaceHeadphones2.png`

When an asset is absent, the popup deliberately falls back to a neutral Segoe Fluent audio-device glyph.
